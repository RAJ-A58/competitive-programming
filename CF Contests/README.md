## 🎯 Contest Rules & Workflow

1. **Fast I/O & Boilerplate**: Always start with [`Template.cpp`](../Template.cpp) to prevent TLE on large $10^5-10^6$ testcases.
2. **Local Testing First**: Use [`judge.py`](../judge.py) (`Ctrl+Shift+B` or `.\judge.bat`) on all sample test cases before submitting.
3. **Rating Categorization**: Solved problems move directly into their rating folders.
4. **Upsolving Discipline**: Unsolved problems are staged in [`Codeforces/Upsolve/`](../Codeforces/Upsolve/) with starter templates.
