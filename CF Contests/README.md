## 🎯 Contest Strategy & Rules

1. **Fast I/O & Boilerplate**: Always start with [`Template.cpp`](../Template.cpp) to prevent TLE on large $10^5-10^6$ testcases.
2. **Local Testing First**: Use [`judge.py`](../judge.py) (`Ctrl+Shift+B` or `.\judge.bat`) on all sample test cases before submitting.
3. **Edge Case Checking**: Test extremes ($n = 1$, max values, all equal elements, parity, empty/overflow cases) before submitting to avoid unnecessary penalty points.
4. **Upsolving Discipline**: Upsolve at least 1 problem past the last one solved live within 24–48 hours of contest completion.
