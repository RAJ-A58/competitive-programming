# 🎯 Upsolve Directory

This folder is dedicated to **upsolving** — problems from live contests or practice sets that were attempted or missed, and need to be analyzed and solved.

---

## 🔁 Upsolving Workflow

1. **Add Target Problem**:
   - Create a file using the problem code (e.g., `2280D.cpp`) with the standard starter template.
   - Link the problem URL in the header comment.
2. **Analyze & Solve**:
   - Read editorials or tags if stuck for > 30-45 minutes.
   - Code the approach and test locally with `judge.bat` (`Ctrl+Shift+B`).
3. **Graduate to Rating Folder**:
   - Once AC, move the solution file into the corresponding rating directory:
     - Rating 800–1100 ➔ [`../Rating_0800_1100/`](../Rating_0800_1100/)
     - Rating 1200–1400 ➔ [`../Rating_1200_1400/`](../Rating_1200_1400/)
     - Rating 1500+ ➔ [`../Rating_1500_plus/`](../Rating_1500_plus/)
